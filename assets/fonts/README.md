# Fonts

- **Cinzel** (Natanael Gama) and **EB Garamond** (Georg Duffner, Octavio Pardo), Latin subsets, from Google Fonts.
- Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling them with the game.
- Served from here so the game doesn't depend on another site at runtime.
