# Reference code map

**Only for the coding session.** The old game's repository may be read as a reference for reusable code (04-build-plan.md section 2). Its code uses a franchise's names. This map translates them. **Never copy those names, card data, art or text into the new game.**

| Old game (reference code only) | New game |
|---|---|
| Pokémon card | **Character card** |
| *(new)* | **Monster card** |
| Trainer card | **Campaign card** |
| Trainer Objective | **Quest** |
| Partner | **Legendary Hero** |
| Trainer Command | **Campaign Order** |
| Command card | **Action card** |
| Supporter card | **Event card** |
| Item card | **Item card** |
| Location card | **Location card** |
| Default Location | **the Wilds** |
| PokéMart | **the Market** |
| PokéDollars ($) | **Gold** (shown as a coin icon) |
| Recognition | **Renown** |
| Player Character | **Warlord** |
| Pokémon League Tournament | **the Last Battle** |
| Breakfast | **Dawn** |
| Supper | **Dusk** |
| Type (Fire, Water…) | **Class** (Fighter, Wizard…) |
| Physical / Special attack | **Martial / Arcane** attack |
| Defence / Special Defence guard | **Shield / Ward** guard |
| Strength (the stat that takes damage) | **Health** |
| Attack | **Attack** |
| Light / Mid / Heavy series | **Light / Mid / Heavy** series |
| Slow / Steady / Swift | **Slow / Steady / Swift** |
| Ready, Active, Spent, Retain, Release, Favour, Exert, Exhaust, Released Pile | Unchanged |

**Other names in the old code:** `Pokemon`/`pokemon` → `Creature` (the shared code path for Characters and Monsters); `trainer` → `campaign`; `partner` → `hero`; `command` → `action`; `supporter` → `event`; `mart` → `market`; `dollars` → `gold`; `recognition` → `renown`; `tournament` → `lastBattle`; `breakfast` → `dawn`; `supper` → `dusk`; `strength` → `health`.
